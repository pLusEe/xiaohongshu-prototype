# 小红书社区互动原型

以「晒赞 → 共同兴趣 → 主动交流」为核心的本地交互原型。使用 HTML、CSS 和原生 JavaScript，包含首页、笔记、主页、共同赞过、共同关注、分享与聊天。

## 运行

下载或克隆整个仓库后，在外部 Chrome 打开 `index.html`，无需安装依赖或构建。保留 `assets/` 与页面文件的相对位置。

也可以在仓库目录运行：

```bash
python3 -m http.server 8080
```

然后打开 `http://localhost:8080/`。

## Vercel 部署

在线原型：https://xiaohongshu-prototype.vercel.app/

项目位于 Vercel 的 `pluses-projects/xiaohongshu-prototype`，按静态站点发布，不需要构建。当前已关闭该项目的 Vercel 登录保护。后续更新在仓库目录执行：

```bash
vercel deploy --prod --yes --scope pluses-projects --project xiaohongshu-prototype
```

`vercel.json` 保留静态部署配置；`.vercelignore` 排除参考截图、验证材料、脚本、文档和未使用的原始大字体，保留页面需要的资源。2026-10-26 首次生产部署已确认 Ready。发布后曾因域名解析异常访问超时，解析恢复后，未登录 Chrome 已通过首页、点赞与晒赞、个人晒赞页、找同好、分享及自动回复链路检查；脚本和字体与本地源码一致，没有运行时错误或资源 HTTP 错误，390px 移动视口无横向溢出。

## 体验入口

- 打开页面后，桌面右侧提供 6 步主线操作引导：赞过笔记 → 晒赞 → 查看自己的晒赞 → 找同好 → 聊一聊 → 继续对话。根据手机里的真实操作自动推进，每次只提示当前动作；无需点开始或下一步。可跳过、重来，偏离体验时可返回当前任务。
- 首次晒赞弹层保留笔记卡、用途说明和一句可见范围提示：“找到也喜欢这篇的人，聊聊共同话题。”“仅公开这一篇，不影响其他赞过。可随时撤回。”右侧引导仅保留进度、当前动作及必要操作，去掉重复介绍、解释小字和下一步预告。
- 发现推荐筛除已经赞过、收藏或浏览过的笔记，首张展示可用于主线的新图文；引导共用首页推荐顺序，从顶部开始。重来更新推荐并回到顶部，保留历史点赞、收藏、晒赞、浏览记录和消息。正在首页操作时卡片留在原位，下一次加载推荐时筛除；没有新的演示推荐时显示空态。
- 五项补充体验仅覆盖本次功能：首页长按晒赞、详情长按晒赞、赞过页加入与撤回、共同兴趣、他人主页共同关系入口。主线已实际体验的入口同步标记完成，长按须实际晒赞后才算完成。切入补充后可返回主线页面和滚动位置。
- 指引使用网页最上层的浅色填充高光，填充透明度约 10%，以 3 秒周期轻微呼吸，独立于手机裁切和缩放，不拦截操作；仅标示可见控件，随用户滚动和弹层重新定位，不自动滚动手机页面。新页面从顶部打开，返回保留浏览位置，聊天显示最新消息。找同好的引导跟随首位推荐；他人主页的共同赞过与共同关注在同一行，分别可点击。窄屏面板显示在手机下方，手机视口通过「引导」展开。
- `index.html#/feed`：发现首页。
- `index.html#/profile/lin/liked/notes`：自己的赞过，支持全部/晒赞筛选。
- `index.html#/kindred`：找同好。
- `index.html#/profile/author-work/liked`：他人的赞过；当前演示内容取其晒赞记录。
- `index.html#/note/herb-food`：多图笔记。
- `index.html#/messages`：本地消息与聊天。

空心表示未点赞，红心表示普通点赞，黄心表示晒赞。普通点击切换点赞，长按、右键或 Shift+F10 打开管理菜单。普通点赞不会加入晒赞；晒赞是主动让别人看见某一篇喜欢并发现同好，与普通赞过页的可见权限分开。撤回晒赞保留点赞，取消点赞同时撤回晒赞。

Feed 普通点赞不弹反馈；详情页「已点赞 / 晒赞」及晒赞结果条 3 秒后退出，鼠标悬停不延长。共同笔记的「聊一聊」复用转发确认弹窗，留言留空且可选，发送卡片保留同好来源；普通转发不附带该来源。分享面板保持原有好友、渠道和工具，不加入晒赞卡片。

当前包含96篇笔记及演示人物。关注、赞藏、晒赞状态和消息通过当前浏览器的 Local Storage 保存，沿用存储键 `xhs-community-public-likes-v1` 与内部 `publicLikes` 字段以保留既有记录。向同好演示人物发送后约 0.9 秒自动收到本地模拟回复，无需额外点击；取消发送、打开会话和刷新不会生成回复，不连接真实账号、消息服务或推荐系统。`file://` 下的分享图和原图下载按需读取本地资源；保存图片保留原文件字节，并保存当前正在浏览的那张图片。重新体验只重置引导，不清除互动数据。

## 文件

| `index.html`、`app.js` | 页面入口、导航、笔记、分享及交互状态 |

| `assets/` | 本地图片、视频、图标、字体、分享图及来源清单 |
| `scripts/build-download-images.mjs`、`assets/downloads/` | 原图下载资源生成脚本、按需加载的原文件数据及 SHA-256 清单 |
| `public-likes-contract.md` | 当前行为、修订边界和验证记录 |
| `reference/`、`verification/` | 历史参考截图与验证材料 |

## 素材与验证边界

部分界面资产取自用户提供的录屏或截图；新增演示照片为生成素材。对应来源、裁切和处理信息保存在各素材目录的 `source-manifest.json` 或专项来源清单中。照片内的置顶与地点控件已分离为独立界面元素；原图遮挡区域的局部处理不代表无损恢复。

原型按402×874基线适配桌面和小屏。已完成的浏览器验证记录见 `public-likes-contract.md`；没有进行 iPhone 真机最终验收。较早的说明和截图保留作历史依据，当前行为以代码与最新契约为准。
